# Checklists

作業ごとの確認項目をまとめる。

## 毎日の開始前チェック

- 今日のゴールを読んだ
- 今日作るものを説明できる
- 今日出てくる用語を確認した
- どのファイルを触るか確認した

## 環境チェック

- IntelliJ IDEAで `backend/` を開ける
- VS Codeで `frontend/` を開ける
- `java -version` が表示される
- `node -v` が表示される
- `npm -v` が表示される
- `git --version` が表示される
- Rancher Desktopが起動している
- `docker --version` が表示される
- `docker ps` を実行できる
- DBコンテナが起動している
- Spring BootのDB接続設定を確認した

## AIを使う前のチェック

- 何を作るかを1文で言える
- 変更するファイルを指定できる
- 入力データと出力データを説明できる
- 画面、API、DBのどこに関係する変更か分かる
- 完成後の確認方法を決めている

## AIが生成した後のチェック

- どのファイルが作成・変更されたか確認した
- 生成されたコードを上から読んだ
- 不要なファイルが増えていない
- 今日扱っていない技術が勝手に追加されていない
- APIのURL、HTTPメソッド、JSONの形が資料と合っている
- 自分の言葉で処理の流れを説明できる

## APIを作った後のチェック

- Spring Bootが起動している
- APIのURLが分かる
- ブラウザまたはAPIクライアントでAPIを呼べる
- ステータスコードが成功になっている
- JSONが返っている
- JSONに必要な項目が含まれている

## React画面を作った後のチェック

- Reactが起動している
- 画面が表示される
- Consoleにエラーが出ていない
- 固定データが表示される
- 入力フォームに文字を入力できる
- ボタンを押したときの動きが確認できる

## ReactとAPIをつないだ後のチェック

- NetworkでAPIが呼ばれている
- APIのURLが正しい
- HTTPメソッドが正しい
- リクエストJSONが想定通り
- レスポンスJSONが想定通り
- API結果がstateに入っている
- 画面が更新される

## 画像表示のチェック

- APIレスポンスに `imageUrl` が含まれている
- `imageUrl` が空ではない
- URLをブラウザで開くと画像が表示される
- Reactの `img` タグの `src` に `imageUrl` を渡している
- 画像がないときの表示崩れが大きくない

## エラー時のチェック

- Consoleにエラーが出ていないか
- NetworkでAPIが呼ばれているか
- ステータスコードは何か
- レスポンスにエラーメッセージがあるか
- Spring Bootログに例外が出ていないか
- DBにデータが保存されているか

## 完成時のチェック

- お店を登録できる
- お店一覧を表示できる
- お店を編集できる
- お店を削除できる
- 地域で絞り込める
- ジャンルで絞り込める
- ステータスで絞り込める
- 画像URLで画像を表示できる
- 画面操作とAPIの対応を説明できる
